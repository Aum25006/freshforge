# Contributing

## Branches
- `main` is always the stable, reviewed version. Never commit to it directly.
- Create your own branch for every task: `yourname/short-description` (e.g. `shivangi/design-tokens`).
- Push your branch to GitHub so others can pull it and look at it.

## Workflow
1. `git pull` on main, then `git checkout -b yourname/task`
2. Make changes, then `git add .` and `git commit -m "what and why"`
3. `git push -u origin yourname/task`
4. Open a Pull Request on GitHub; someone else reviews it, then merge.

## Rules
- Pull often, to keep your branch close to main.
- No big videos or raw photo exports in the repo; compress images first.
- Once DESIGN_SYSTEM.md exists, use its tokens only (no ad-hoc colors or pixel values).
